# DAY-01 HTML FUNDAMENTALS

HTML = HyperText Markup Language
- bahasa yang digunakan untuk menentukan struktur dan makna konten halaman web

## HTML Element
keseluruhan struktur yang terdiri dari 

*misalnya*
```html
<h1>My Profile</h1>
<p>Halo, aku Adis</p>
<button>Contact Me</button>
```
h1 -> heading utama
p -> paragraf
button -> tombolnya
